# FrotaCLT

Sistema de Gestão de Frotas desenvolvido para empresas que desejam otimizar o controle operacional de seus veículos, motoristas e custos.

O FrotaCLT reúne em uma única plataforma todas as informações necessárias para o gerenciamento da frota, proporcionando maior organização, redução de custos e suporte à tomada de decisões.

## Funcionalidades

- 🚛 Cadastro de veículos
- 👨‍✈️ Cadastro de motoristas
- ⛽ Controle de abastecimentos
- 🔧 Manutenções preventivas e corretivas
- 🛢️ Controle de troca de óleo
- 💰 Controle de despesas
- 📅 Controle de documentos e vencimentos
- 📊 Dashboard com indicadores
- 📈 Relatórios gerenciais
- 🔐 Controle de usuários

## Tecnologias

- ASP.NET
- C#
- SQL Server
- JavaScript
- HTML5
- CSS3

## Objetivo

Facilitar o gerenciamento de frotas empresariais, proporcionando controle operacional, redução de custos e acompanhamento completo dos ativos da empresa.
